# BLK-001 — Drag & drop figé visuellement dans l'éditeur (React 19)

| Friction                                                                        | Cause réelle                                                                         | Solution                                            | Statut |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------- | ------ |
| Le composant `react-rnd` se figeait visuellement pendant le drag dans l'éditeur | `react-rnd` utilisé en mode contrôlé (`position`/`size`), incompatible avec React 19 | Passer `react-rnd` en mode non contrôlé (`default`) | résolu |
