# BLK-007 — Le CLI shadcn a mal installé les fichiers à chaque ajout de composant

| Friction                                                                                                                                                                                                                                                                                                                                                                                                              | Cause réelle                                                                                                                                              | Solution                                                                                                                                                                                                                                                                                                                              | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Chaque `pnpm dlx shadcn@latest add ...` (registre WigggleUI ou standard) écrivait dans un dossier littéral `./@/...` au lieu de résoudre l'alias `@/` vers `src/` — répété à chaque install de cette session (déjà connu : GLRN-121). Un des appels a de plus tiré `scroll-area`/`switch` construits sur Base UI + package `cn` générique au lieu de Radix + `@/lib/utils` du reste du projet (déjà connu : GLRN-180) | Bug connu du CLI shadcn sous Windows sur la résolution d'alias, et changement de registre par défaut (base-nova/Base UI) pour certains composants récents | Déplacer manuellement les fichiers depuis `./@/...` après chaque install, supprimer le dossier résiduel ; réécrire à la main `scroll-area.tsx`/`switch.tsx` avec `@radix-ui/react-scroll-area`/`@radix-ui/react-switch` + `@/lib/utils` pour rester cohérent avec le reste du design system (voir [BDR-010](../decisions/BDR-010.md)) | résolu |

## Références

- [BDR-010](../decisions/BDR-010.md) — décision générale adoptée suite à ce blocage
- Déjà documenté globalement : GLRN-121 (alias Windows), GLRN-180 (Base UI par défaut)
