# BLK-015 — Écran de veille ne se lançait pas systématiquement via le bouton TV

| Friction                                                                                                                         | Cause réelle                                                                                                                                                                                                                                                                                                                    | Solution                                                                                                                                                                                                           | Statut |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| "Économiseur d'écran" sur la TV ne lançait pas Ambio de façon fiable — ne fonctionnait qu'après avoir rouvert l'app manuellement | `APP_AUTO_START: ignore`, une restriction propriétaire TCL bloquant le `bindService` du système vers `MyDreamService`, invisible dans `screensaver_components`/`screensaver_enabled` (tous deux corrects) — confirmé en direct via `adb logcat DreamManagerService:V DreamController:V` montrant `Unable to bind dream service` | `adb shell cmd appops set <pkg> APP_AUTO_START allow` (accordé une fois) + ajout de `DreamRegistrar`/`BootReceiver` pour réaffirmer automatiquement Ambio comme dream actif après redémarrage TV / mise à jour app | résolu |
