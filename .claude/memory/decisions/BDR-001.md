# BDR-001 — WebSocket de sync sur `/ws` plutôt que `/`

| Décision                                      | Pourquoi                                                                            | Alternatives considérées                            | Statut |
| --------------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- | ------ |
| Servir le WebSocket de synchro live sur `/ws` | Le HMR interne de Vite écoute déjà sur `/` pour le même port HTTP — collision sinon | Un seul WebSocket partagé sur `/` (rejeté, conflit) | actif  |
