# BDR-003 — Déploiement RPi via `git pull`, plus scp/tar manuel

| Décision                                                                                        | Pourquoi                                                                                                                                                                   | Alternatives considérées                                                                     | Statut |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------ |
| Le RPi est un clone git du repo GitHub ; déployer = `git pull` + `pnpm install` + `pm2 restart` | Le dev se fait sur le PC (`pnpm dev`, localhost:5173) — il fallait un moyen répétable de propager les changements sans re-copier manuellement l'arborescence à chaque fois | `tar`/`scp` manuel (utilisé en tout début de session, remplacé dès que le repo git a existé) | actif  |
