# BDR-006 — Wrapper Gradle committé + script de build Android autonome

| Décision                                                                                                                                                                  | Pourquoi                                                                                                                                                                                                                                                                   | Alternatives considérées                                                                                                | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------ |
| `gradlew`/`gradlew.bat`/`gradle-wrapper.jar` sont committés dans le repo, et `android-app/build-and-install.sh` encapsule `assembleDebug` + `adb install` en une commande | Aucun Android Studio/SDK n'était disponible en CLI sur le PC — dépendre du cache Gradle d'Android Studio (chemin variable, hash de dossier imprévisible) n'est pas reproductible ; committer le wrapper + scripter le build rend la compilation possible sans ouvrir l'IDE | Toujours passer par Android Studio pour builder (fonctionnel mais plus lent, nécessite l'IDE ouvert à chaque itération) | actif  |
