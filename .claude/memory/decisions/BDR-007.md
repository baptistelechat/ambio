# BDR-007 — Placement des widgets en grille façon écran d'accueil Android

| Décision                                                                                                                                                                                        | Pourquoi                                                                                                                                                                                   | Alternatives considérées                                                                                                           | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Chaque widget a une taille fixe en cellules (ex: "sm" = 2x2, "md" = 4x2) et se pose sur une grille (`col`/`row` entiers) au lieu d'un positionnement libre en pixels (`x`/`y`/`width`/`height`) | Baptiste voulait une UX de placement type launcher Android plutôt qu'un canvas de design libre — évite aussi le chevauchement/désalignement des widgets constaté avec le drag & drop libre | Garder le positionnement libre existant (`react-rnd` avec `default={{x,y,width,height}}`), ou une grille CSS Grid native sans drag | actif  |
