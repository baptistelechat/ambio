# BDR-008 — Réglages de widgets pilotés par des données, pas par du code par type

| Décision                                                                                                                                                                                    | Pourquoi                                                                                                                                                                                                                                         | Alternatives considérées                                                                                         | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------ |
| Un fichier `widgetSettings.ts` déclare, par type de widget, la liste des champs de réglage (`text`/`select` + options) ; `SettingsPanel.tsx` boucle dessus et rend les champs génériquement | Le panneau avait un `if (widget.type === "weather")` par type — intenable dès qu'on est passé de 4 à 21 types de widgets (WigggleUI), et chaque nouveau widget avec réglages (météo, horloges multi-fuseaux) aurait demandé un nouveau bloc `if` | Garder les conditions codées en dur par type dans `SettingsPanel.tsx`, un composant de settings dédié par widget | actif  |
