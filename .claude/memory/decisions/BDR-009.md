# BDR-009 — Météo WigggleUI sur réglage `location`, pas géolocalisation navigateur

| Décision                                                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                                                    | Alternatives considérées                                                                           | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------ |
| Les widgets météo WigggleUI (utilisant à l'origine `navigator.geolocation` + fallback IP) sont réécrits pour utiliser le réglage `location` (texte) déjà en place sur le widget météo maison, via un hook partagé `useConfiguredWeather` qui réutilise le géocodage Open-Meteo existant | La géolocalisation navigateur reste bloquée en "Loading..." indéfiniment dans la WebView Android de la TV (pas de prompt de permission) — constaté en test avant correction | Garder la géolocalisation navigateur, ou dupliquer une logique de géocodage propre à chaque widget | actif  |
