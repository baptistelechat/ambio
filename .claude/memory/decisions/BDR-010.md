# BDR-010 — Registre tiers divergent : garder les primitives du projet, ne prendre que le nouveau

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                 | Pourquoi                                                                                                                                                                   | Alternatives considérées                                                                            | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------ |
| Quand un registre shadcn tiers (WigggleUI, ou le CLI shadcn lui-même) renvoie une version d'un composant déjà présent (`button`, `label`, `separator`, `utils`) construite sur une base différente (Radix vs Base UI, `cn` générique vs `@/lib/utils`), on garde la version du projet et on n'installe que les composants réellement nouveaux (`badge`, `scroll-area`, `switch`, etc.), en vérifiant leurs imports avant de les intégrer | Éviter de faire cohabiter deux design systems dans le même repo (styles divergents, deux librairies de primitives) — repéré plusieurs fois pendant l'intégration WigggleUI | Écraser les fichiers existants avec ceux du registre tiers, ou ne jamais utiliser de registre tiers | actif  |
