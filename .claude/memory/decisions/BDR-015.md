# BDR-015 — QR code widget : `react-qr-code` (SVG) plutôt qu'une lib canvas

| Décision                                                                                                                                                                | Pourquoi                                                                                                                                                                                                     | Alternatives considérées                                                                                                                                          | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Génération du QR code (widget Wi-Fi/URL) via `react-qr-code`, un rendu SVG pur sans canvas, `peerDependencies: { react: "*" }` (compatible React 19 sans avertissement) | Cohérent avec la contrainte du projet d'éviter les frameworks/rendus lourds côté TV (SoC modeste) ; pas de dépendance à un canvas qui doit se redessiner, juste du SVG déclaratif comme le reste des widgets | `qrcode.react` (a aussi une variante SVG mais API plus lourde) et `qrcode` (Node, génération de string SVG manuelle, plus de code custom pour un composant React) | actif  |
