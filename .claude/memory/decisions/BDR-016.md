# BDR-016 — Fête du jour : API `nameday.abalin.net` plutôt que `nominis.cef.fr`

| Décision                                                                                                                                                  | Pourquoi                                                                                                                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                                                                             | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Widget "Fête du jour" alimenté par `https://nameday.abalin.net/api/V2/today/UTC` (champ `data.fr`), pas par `https://nominis.cef.fr/json/saintdujour.php` | Nominis renvoie le saint du calendrier liturgique officiel de l'Église, pas le calendrier civil affiché sur les calendriers muraux/bulletins météo — testé en direct : le 12/09 donnait "Le saint nom de Marie" (Nominis) au lieu d'"Apollinaire" (calendrier civil, confirmé par abalin.net et par Baptiste) | `api_fetes_prenoms_france` (repo GitHub trouvé en recherche initiale, instance publique morte/hors ligne) ; liste locale statique (écartée à la demande explicite de Baptiste, qui voulait une source fiable/à jour) | actif  |
