# BDR-017 — Qualité de l'air éclatée en widgets unitaires + une vue combinée

| Décision                                                                                                                                                                                                               | Pourquoi                                                                                                                                                                                                                                    | Alternatives considérées                                                                                                                                                                             | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 4 widgets unitaires (AQI, Indice UV, Pollen, Particules fines PM2.5) partageant le même hook `useAirQuality`, plus un 5e widget "Qualité de l'air détaillée" (6x1) qui réunit les 4 indices dans une seule bande large | Premier essai en un seul widget carré 4x2 avec tous les indices jugé trop dense/petit par Baptiste ; le découpage en widgets unitaires permet de choisir uniquement l'indice pertinent, la vue combinée sert de résumé compact en une ligne | Un unique widget "tout-en-un" (rejeté, illisible en petite taille) ; dupliquer le fetch par widget plutôt qu'un hook partagé (écarté, un seul hook `useAirQuality` évite 4 appels réseau redondants) | actif  |
