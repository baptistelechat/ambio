# BDR-018 — Palette WiggleUI sous-catégorisée par thème

| Décision                                                                                                                                                                                                                                 | Pourquoi                                                                                                                                                | Alternatives considérées                                                                                                                                                | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Introduction d'un second niveau de regroupement (`wiggleSubcategory` dans `types.ts`) sous la catégorie "wiggleui" : Horloges, Calendriers, Météo, Qualité de l'air, Système, Utilitaires, chacun avec son sous-titre dans `Palette.tsx` | La liste plate de widgets WigggleUI est passée de 17 à 25 entrées dans la même session — devenait illisible sans repère visuel pour retrouver un widget | Garder une seule liste plate (illisible à cette taille) ; renommer les widgets avec un préfixe textuel par thème (écarté, moins lisible qu'un vrai regroupement visuel) | actif  |
