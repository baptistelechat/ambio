# BDR-019 — Widget "Statut Raspberry Pi" limité à 3 métriques (température, RAM, uptime)

| Décision                                                                                                                                                                        | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                       | Alternatives considérées                                                                                                                                              | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le widget affiche uniquement température CPU, RAM utilisée et uptime, en une barre compacte 4x1 (`wiggleSystemStatusMd1`, remplace l'ancien widget carré `wiggleSystemStatus1`) | "Charge" (moyenne de charge CPU) prêtait à confusion avec une charge de batterie sur un appareil qui reste branché en permanence, et faisait doublon avec la température (un CPU chargé chauffe déjà). "Alimentation" (détection de sous-tension via throttling), bien que plus diagnostique, écartée pour garder le widget compact et éviter d'ajouter une métrique de plus à interpréter sur l'écran ambiant | 5 métriques (Temp, RAM, Charge CPU via `os.loadavg()`, Alimentation via `vcgencmd get_throttled`, Uptime), envisagées puis réduites après clarification avec Baptiste | actif  |
