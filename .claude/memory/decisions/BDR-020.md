# BDR-020 — Largeur de widget pilotée par override d'instance (`settings.width`)

| Décision                                                                                                                                                                                                                                                           | Pourquoi                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                            | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le bandeau d'actualités lit sa largeur (4 à 16 colonnes) depuis `widget.settings.width` plutôt que la taille fixe par type — appliqué uniformément par les 3 renderers (`Canvas.tsx`, `StaticGrid.tsx`, `RotatedGrid.tsx`) via un helper `getWidgetCols()` partagé | Les widgets avaient jusqu'ici une taille fixe par TYPE (`widgetDefaults[type].cols`) ; ce widget avait besoin d'une largeur réglable par INSTANCE sans faire proliférer les types ni casser le modèle de grille existant | Un type de widget distinct par largeur (rejeté, prolifération) ; resize handles natifs react-rnd (rejeté, casse le snap par colonnes déjà en place) | actif  |
