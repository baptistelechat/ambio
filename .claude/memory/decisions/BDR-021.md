# BDR-021 — Flux RSS résolus uniquement via un catalogue serveur

| Décision                                                                                                                                                                                | Pourquoi                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                         | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------ |
| Le client envoie des identifiants de catalogue (`feedIds`/`topicIds`), jamais des URLs — le serveur résout ces ids contre `NEWS_FEED_CATALOG`/`NEWS_TOPIC_CATALOG` avant tout fetch RSS | Une première version acceptait des URLs RSS arbitraires saisies par l'utilisateur, proxy-fetchées côté serveur — un vecteur SSRF classique (le serveur fait une requête vers n'importe quelle URL fournie par le client, y compris vers le réseau local) | Garder la saisie libre d'URL avec validation de protocole seule (rejeté, insuffisant contre le SSRF vers le LAN) | actif  |
