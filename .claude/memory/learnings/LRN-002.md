# LRN-002 — `transform: scale()` exige un nombre pur, pas une longueur `vw`/`vh`

| Pattern observé                                                                                                                                                                                                                                                                           | Contexte                                                                                                           | Application future                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transform: scale(min(100vw / 1920, 100vh / 1080))` est silencieusement invalide — `min()`/`calc()` avec des unités `vw`/`vh` produisent une **longueur** (px), or `scale()` attend un **nombre** sans unité. Le navigateur rejette toute la déclaration `transform`, sans erreur console | Mise à l'échelle CSS pure d'un canvas logique (1920×1080) pour remplir l'écran, dans `Screensaver.tsx` (`rpi-app`) | Calculer le ratio d'échelle en JS (`Math.min(window.innerWidth/W, window.innerHeight/H)`, via `resize`/`ResizeObserver`) et l'injecter comme nombre dans `transform: scale(N)` — jamais essayer de dériver un facteur d'échelle sans unité directement en CSS depuis des unités de longueur |
