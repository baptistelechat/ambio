# LRN-003 — Un flex item dimensionné explicitement peut être réduit sous cette taille sur l'axe principal

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                                         | Application future                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une `<div>` avec `width: 1920px` inline, enfant direct d'un `display:flex` (axe principal = ligne), voyait sa largeur **calculée** ramenée à celle du conteneur (960px) malgré le style inline — `flex-shrink: 1` est la valeur par défaut, et flexbox peut réduire un item sous sa largeur déclarée sur l'axe principal pour tenir dans le conteneur. L'axe transversal (hauteur, via `align-items`) n'est lui jamais affecté par ce mécanisme, d'où un bug qui ne touche qu'une seule dimension et donc difficile à soupçonner d'un problème flexbox au premier abord | `Screensaver.tsx` (`rpi-app`) : un canvas 1920×1080 mis à l'échelle par `transform: scale()`, enfant d'un conteneur `flex items-center justify-center` pour le centrage — rendu à moitié largeur sur la vraie TV | Tout élément à taille CSS fixe/explicite placé comme enfant direct d'un conteneur flex doit recevoir `flex-shrink: 0` (Tailwind : `shrink-0`) si sa taille ne doit jamais être négociée par l'algorithme flex. Vérifier `getComputedStyle(el).width` (pas seulement le style inline/attribut) en cas de rendu inattendu |
