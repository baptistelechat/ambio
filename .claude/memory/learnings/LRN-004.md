# LRN-004 — Déboguer une WebView Android à distance via CDP brut sans `chrome://inspect`

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Contexte                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Quand `chrome://inspect` n'est pas accessible (ex. outil d'automatisation qui refuse de naviguer vers une URL `chrome://`), on peut parler directement au protocole DevTools : `WebView.setWebContentsDebuggingEnabled(true)` côté app, puis `adb shell cat /proc/net/unix \| grep webview_devtools` pour trouver le socket (`webview_devtools_remote_<pid>`), `adb forward tcp:PORT localabstract:<socket>`, `curl http://localhost:PORT/json` pour lister les pages et récupérer `webSocketDebuggerUrl`, puis un petit script (Node a un `WebSocket` global natif) envoyant `Runtime.evaluate` pour inspecter DOM/styles/valeurs JS en direct | Diagnostic d'un bug de rendu (largeur incorrecte) sur la vraie WebView d'un `DreamService` Android TV, où seule l'inspection en direct (comparer style inline vs `getComputedStyle`) a permis de trouver la cause réelle | Réutilisable pour tout debug de WebView Android (app native ou TV) quand l'IDE/chrome://inspect n'est pas disponible ou pas utilisable par l'outil d'automatisation en cours ; comparer systématiquement style inline et style calculé quand un rendu semble incohérent avec le code |
