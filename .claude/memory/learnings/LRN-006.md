# LRN-006 — `react-rnd` `dragGrid` + `scale` parent : snap peu fiable, forcer via le ref

| Pattern observé                                                                                                                                                                                                                                                                           | Contexte                                                                                                          | Application future                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le prop `dragGrid` de `react-rnd`, combiné à un `transform: scale()` sur le conteneur parent (canvas réduit dans un éditeur), produit parfois des positions totalement hors-grille (ex: `768.72px` au lieu d'un multiple de 120) — confirmé en loggant `d.x`/`d.y` reçus par `onDragStop` | Éditeur avec un canvas mis à l'échelle (`scale={scale}` passé à `Rnd` pour compenser le zoom visuel de l'éditeur) | Ne pas se fier à `dragGrid` dans ce contexte : calculer soi-même la case arrondie dans `onDragStop`, puis forcer visuellement cette position via `rndRef.current.updatePosition({x, y})` (API impérative, pas de props contrôlées — évite le bug de freeze React 19 documenté dans [LRN-001](LRN-001.md)) |
