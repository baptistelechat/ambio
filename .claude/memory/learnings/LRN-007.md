# LRN-007 — Grille CSS en dégradé répété : le dernier trait (bord droit/bas) manque toujours

| Pattern observé                                                                                                                                                                                                                                                                            | Contexte                                                                                                           | Application future                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une grille visuelle dessinée avec 2 `linear-gradient` répétés (`background-size` = taille de cellule) ne trace un trait qu'au _début_ de chaque tuile — la dernière colonne/ligne n'a donc jamais son trait de droite/bas, même si la boîte fait un multiple exact de la taille de cellule | Overlay de grille éditable (case = widget) sur un canevas de taille fixe, activable/désactivable par l'utilisateur | Fermer les bords manquants avec un `box-shadow: inset -Npx 0 0 <couleur>, inset 0 -Npx 0 <couleur>` sur le même conteneur, en plus du `background-image` tuilé |
