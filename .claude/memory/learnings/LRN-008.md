# LRN-008 — Traits fins (< 2px) invisibles sous un `transform: scale()` < 1

| Pattern observé                                                                                                                                                                                                                                                                                                                  | Contexte                                                                                                                 | Application future                                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Des traits de grille dessinés à 1px dans l'espace "logique" (avant mise à l'échelle) deviennent sous-pixel et disparaissent visuellement une fois le conteneur réduit par `transform: scale(0.4)` — plusieurs tentatives (opacité, `mix-blend-mode: difference`) n'y changeaient rien, seule l'épaisseur du trait était en cause | Overlay de grille dans un éditeur dont le canevas logique (1920×1080) est visuellement réduit pour tenir dans la fenêtre | Dessiner les traits assez épais dans l'espace non mis à l'échelle (ex: 3px) pour qu'ils restent ≥ 1px visible après la réduction la plus forte attendue |
