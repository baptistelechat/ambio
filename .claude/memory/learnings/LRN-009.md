# LRN-009 — Un `click` natif se déclenche toujours après un drag relâché

| Pattern observé                                                                                                                                                                                                                      | Contexte                                                                           | Application future                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Après un glisser-déposer (mousedown → mousemove → mouseup), le navigateur émet quand même un événement `click` natif sur l'élément relâché, déclenchant à tort un handler `onClick` prévu pour la sélection/l'ouverture d'un panneau | Widget déplaçable (`react-rnd`) avec un `onClick` qui ouvre un panneau de réglages | Poser un flag `ref` (ex: `draggedRef`) mis à `true` dans `onDrag`, vérifié et réinitialisé en tout début de `onClick` — si le flag est actif, ignorer le clic au lieu d'exécuter l'action |
