# LRN-012 — `height:100%` sur un `position:fixed` ignore la barre d'adresse mobile

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                 | Contexte                                                                                              | Application future                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `height: 100%` (Tailwind `h-full`) sur un élément `position: fixed` sans `top` se résout par rapport à la "large viewport" (hauteur maximale, barre d'adresse supposée masquée) — pas la hauteur réellement visible. Écart invisible en émulation Chrome DevTools (résidu de 2px), flagrant sur un vrai Android Chrome avec la barre d'adresse affichée (~50-60px de contenu poussé hors écran) | Tiroir mobile (`vaul`) de `rpi-app` en plein écran — voir [ZBLK-010](../archive/blockers/ZBLK-010.md) | Pour tout élément `fixed` censé occuper tout l'écran visible, toujours utiliser `h-dvh`/`100dvh` (dynamic viewport height, s'ajuste en temps réel à la barre d'adresse) plutôt que `h-full`/`height:100%`. Tester sur un vrai device mobile, pas seulement l'émulateur Chrome DevTools — celui-ci ne reproduit pas cet écart |
