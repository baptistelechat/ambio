# LRN-014 — Grille CSS plutôt que 2 lignes flex indépendantes pour aligner des colonnes

| Pattern observé                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                        | Application future                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Deux `<div className="flex justify-center gap-X">` empilées, chacune avec 2 items de largeur différente ("10.1 km/h" vs "0 mm"), ne gardent PAS leurs colonnes alignées : chaque ligne centre son propre contenu indépendamment, donc le 2e item de chaque ligne se décale selon la largeur du 1er item de CETTE ligne | Widget "Météo détaillée" (`weather-md-01.tsx`) : Ressenti/Humidité (colonne 2) visuellement décalés l'un par rapport à l'autre malgré un `gap-16` identique sur les deux lignes | Dès que 2+ lignes doivent garder des colonnes alignées avec du contenu de largeur variable, utiliser une seule grille CSS (`grid grid-cols-N`) enveloppant TOUS les items plutôt que plusieurs conteneurs flex empilés — les pistes de la grille sont dimensionnées une fois pour tout le groupe, pas ligne par ligne |
