# LRN-015 — État de drag/preview transitoire : garder local + `createPortal`, pas lever au parent

| Pattern observé                                                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                   | Application future                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un ghost/preview affiché pendant un drag, dont l'état est levé vers un ancêtre commun (ex: `Canvas`) pour être visible au-dessus de tous les widgets, force ce parent à re-render à CHAQUE frame de drag — ce qui re-render TOUS les composants frères (widgets avec animations, intervals...), même ceux qui n'ont rien à voir avec le drag en cours | Éditeur Ambio : ajout d'un aperçu rouge de la case cible pendant le déplacement d'un widget — a rendu le drag perceptiblement lent dès l'ajout de cet état sur `Canvas` (voir [ZBLK-011](../archive/blockers/ZBLK-011.md)) | Garder l'état transitoire (drag, hover, preview) LOCAL au composant qui le déclenche (`useState` dans le widget lui-même). Si ce contenu doit visuellement apparaître au-dessus des autres éléments (z-index global), utiliser `createPortal` vers un conteneur DOM stable plutôt que de lever l'état — seul le composant propriétaire re-render, jamais ses frères |
