# LRN-016 — Tester le CORS (`curl -H Origin`) avant de choisir fetch client vs proxy serveur

| Pattern observé                                                                                                                                                                                                                                                                             | Contexte                                                                                                                                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `curl -s -D - -o /dev/null -H "Origin: http://localhost:5173" "<url>"` révèle immédiatement si une API externe autorise le fetch direct depuis le navigateur (`access-control-allow-origin: *`) ou non — sans avoir à écrire de code ni à ouvrir un navigateur pour le découvrir après coup | Ambio : Nominis et Open-Meteo Air Quality avaient un CORS ouvert (fetch client direct, comme la météo existante) ; les flux RSS français usuels (Le Monde, France Info) n'en ont pas (nécessiteraient un proxy serveur comme `/api/agenda`) — décidé AVANT d'écrire le moindre hook, pas découvert par un bug en prod | Avant d'intégrer une nouvelle API externe dans un widget/composant client, toujours vérifier son CORS avec `curl -H "Origin: ..."` en premier réflexe — ça détermine directement l'architecture (fetch direct vs endpoint proxy à ajouter côté serveur) au lieu de le découvrir tardivement via une erreur CORS en navigateur |
