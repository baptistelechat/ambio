# LRN-017 — Erreur console du Browser pane : peut être un résidu HMR, revérifier sur onglet neuf

| Pattern observé                                                                                                                                                                                                                                                                                                 | Contexte                                                                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Une erreur `ReferenceError` citant une variable/fonction qui n'existe plus nulle part dans le code source (vérifié par `Grep`) peut quand même apparaître dans `read_console_messages`, même après un `navigate` (rechargement) de la même page — l'onglet garde un état JS/HMR périmé d'une session précédente | Ambio : après avoir annulé (`git checkout`) une modification de `Canvas.tsx`, l'onglet du Browser pane continuait à afficher `handleDragPreview is not defined` malgré un rechargement complet, alors que `Grep` confirmait l'absence totale de cet identifiant dans le repo | Avant de traiter une erreur console comme un vrai bug : `Grep` l'identifiant en cause dans le code source. S'il n'existe nulle part, ouvrir un ONGLET NEUF (`tabs_create` + `navigate`) plutôt qu'un simple rechargement de l'onglet existant — un onglet frais n'hérite d'aucun état HMR périmé |
