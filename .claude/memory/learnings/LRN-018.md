# LRN-018 — Composant dupliqué 3x avec des layouts différents : extraire via une variant `cva`, pas un 3e copier-coller

| Pattern observé                                                                                                                                                                                                                                                                                           | Contexte                                                                                                                                                                                                                                                      | Application future                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un même petit composant présentationnel (icône + valeur + tooltip, `InfoItem`) existait déjà en double dans `air-quality-md-01.tsx` (layout horizontal, avec unité) et `weather-md-01.tsx` (layout vertical empilé, sans unité) — sur le point d'en écrire une 3e copie pour le nouveau widget statut RPi | Plutôt qu'une 3e duplication, extraction en composant partagé `components/ui/info-item.tsx` avec une prop `layout: "row" \| "stack"` pilotée par `cva`, migrant les 2 usages existants sans changement visuel (vérifié par lint + build + rendu Browser pane) | Avant de dupliquer un petit composant une 3e fois, `grep` les usages existants pour repérer les variations réelles (layout, props optionnelles), puis les couvrir avec une seule prop `cva` plutôt que forcer un usage unique — évite de casser les 2 usages déjà en prod pendant l'extraction |
