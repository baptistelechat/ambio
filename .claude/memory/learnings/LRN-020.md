# LRN-020 — Un service Android démarré par le système peut échouer silencieusement via un app-op OEM

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                          | Contexte                                                                                                                                         | Application future                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `DreamController: Unable to bind dream service` dans `adb logcat` sans autre détail exploitable — cause réelle trouvée via `adb shell cmd appops get <pkg>` : `APP_AUTO_START: ignore`, une restriction propriétaire TCL bloquant le démarrage en arrière-plan, invisible dans les réglages standards Android (`screensaver_components`/`screensaver_enabled` étaient pourtant corrects) | Écran de veille Ambio qui ne se lançait pas via le bouton "Économiseur d'écran" de la TV alors que tous les réglages système semblaient corrects | Quand un service/broadcast lancé par le système échoue sans exception exploitable côté app, vérifier `adb shell cmd appops get <pkg>` (app-ops OEM comme `APP_AUTO_START` sur les firmwares chinois/MTK) avant de creuser plus loin côté code — corrigible en direct via `adb shell cmd appops set <pkg> APP_AUTO_START allow` |
