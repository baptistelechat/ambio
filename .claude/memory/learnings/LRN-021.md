# LRN-021 — Une appli tierce fluide en vidéo ne garantit pas qu'un `<video>` HTML profite du même chemin matériel

| Pattern observé                                                                                                                                                                                                                                                 | Contexte                                                                                                                                                               | Application future                                                                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hypothèse "Aerial View (vidéo 4K fluide) prouve que la TV a un chemin matériel dédié pour la vidéo, donc générer le bandeau en `<video>` le rendra fluide" invalidée en pratique : le rendu vidéo dans la WebView s'est révélé PIRE que le CSS animé, pas mieux | Tentative de contourner un plafond mesuré à ~5fps (`dumpsys gfxinfo`) en générant le bandeau d'actualités comme vidéo H.264 (ffmpeg côté serveur) plutôt qu'en DOM/CSS | Ne pas construire tout un pipeline (génération, cache, endpoint) sur une hypothèse de "chemin matériel partagé" sans un test minimal préalable (ex : un `<video>` statique de test dans la même WebView) — une appli native tierce fluide n'implique pas qu'une WebView aura le même accès matériel |
