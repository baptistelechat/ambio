# LRN-022 — Ajuster un state dérivé d'une prop pendant le render plutôt que via useEffect

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                        | Application future                                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un state qui doit se réinitialiser quand une prop/valeur dérivée change (ex: reset d'un index à 0 quand la taille d'une liste change) peut être ajusté directement pendant le render — comparer avec un state "previous X" et appeler setState conditionnellement — plutôt que dans un useEffect séparé, qui provoque un rendu supplémentaire (flash de l'ancien état avant correction) | Détecté par react-doctor (`no-adjust-state-on-prop-change`) sur `NewsTickerWidget.tsx` : reset de l'index affiché après un rechargement de flux RSS changeant le nombre d'items | Réflexe à appliquer dès qu'un effet ne fait qu'un setState synchrone déclenché par un changement de dépendance simple — remplacer par un ajustement pendant le render (pattern documenté dans "You Might Not Need an Effect" de la doc React) |
